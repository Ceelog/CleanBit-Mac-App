安全设计

不做盲目的「一键清理」，按风险决定怎么删

市面上很多清理工具只给一个大数字和一键按钮。CleanBit 把每一项按风险分成三档，把选择权交给你。

建议清理

会自动重建的缓存

应用缓存、浏览器缓存（不碰 Cookie、历史记录和密码）、Xcode DerivedData 及包管理器缓存。默认直接删除让空间立刻回来，也可在设置中改为移到废纸篓。

需要确认

默认不勾选，一律进废纸篓

项目构建目录（node_modules、target、.venv）、旧安装包（.dmg、.pkg）、应用残留、AI 旧会话与卸载的应用。一律移到废纸篓，随时可以放回原处。

仅展示

只列出体积，永远不删除

本地 AI 模型（Hugging Face、Ollama、LM Studio）、pnpm store（硬链接存储）和 Docker 虚拟磁盘。只告诉你占了多大，并提示更稳妥的官方清理命令。

坦诚说明 App 沙盒边界

CleanBit 运行在 macOS App Sandbox 内，不要 root 权限，不安装常驻后台的 helper，也不假装能清理系统保护区域：

  • 不碰系统缓存和 APFS 本地快照
  • 不删除 iCloud Drive 云盘文件（由访达处理）
  • 不做「释放内存」「加速 Mac」或杀毒
  • 不在后台静默自动删除任何文件
  • 文件名、路径和文件内容从不离开你的 Mac

常见问题

你可能会关心的问题

为什么 CleanBit 只上架 Mac App Store 且坚持使用沙盒？

App Sandbox 保证了 CleanBit 不需要 root 权限、不安装常驻后台的 helper，只能访问你在系统打开面板中明确授权的文件夹。完全磁盘访问权限是可选的，仅在需要清理废纸篓、Safari 和其他应用容器时才需要打开。

删掉的文件还能恢复吗？

按风险分级处理，确认前会写清楚。「建议清理」中会自动重建的缓存默认直接删除以立即腾出空间（你也可以在设置里改为移到废纸篓）；「需要确认」项、项目产物、手动选择的文件和卸载的应用一律移到废纸篓，可以放回原处。

为什么 CleanBit 不清理 APFS 本地快照或系统缓存？

这些位置受 macOS 系统保护，沙盒应用无法触碰。我们不要求 root 权限，也不假装能清理系统自己管理的空间，只专注处理个人文件夹内明确可安全检查的缓存、开发产物和残留。

CleanBit 会上传我的文件名或路径吗？

不会。扫描、重复文件校验和清理全部在你的 Mac 本地完成，文件名、路径、内容和已安装应用列表从不离开电脑。CleanBit 仅通过 Firebase Analytics 收集匿名使用统计（规则 ID、数量与体积）。

支持哪些 macOS 版本？

CleanBit 使用 SwiftUI 原生开发，支持 macOS 15 及以上版本。
